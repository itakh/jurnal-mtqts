# Jurnal MTQTS — tampilan (GitHub Pages)

Tampilan aplikasi Jurnal MTQTS, Ma'had Tahfizhul Qur'an Tarbiyah Sunnah. Data disimpan di Google Sheet melalui Apps Script (repositori server terpisah dan privat).

Repositori ini **publik** dan sengaja **tidak** memuat data santri maupun sandi; semua data baru dikirim server setelah pengguna masuk.

- Alamat server diatur di `config.js`.
- Berkas lain dibangun ulang dari repositori server dengan `build.py`. Jangan mengubah `index.html` langsung di sini.
